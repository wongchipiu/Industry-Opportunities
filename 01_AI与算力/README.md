# AI 与算力

## 产业主线

AI 产业的投资研究按“需求—计算—互连—内存—制造—电力—应用变现”展开：

```text
模型/应用需求
  → 云与AI工厂资本开支
    → GPU / 定制XPU / CPU
      → HBM / 先进封装 / 晶圆代工
        → 交换芯片 / 光互连 / 存储
          → 服务器 / 供配电 / 制冷
            → token成本下降、使用量增长与应用收入
```

## 当前核心论文

1. AI 基础设施仍处在强资本开支阶段，但计算架构正从单一 GPU 叙事走向 GPU、定制 XPU、CPU 和网络协同。
2. 最大利润池仍在拥有软硬件生态和系统级优化能力的平台，单芯片峰值性能不是充分条件。
3. 更低的单位 token 成本可能通过需求弹性扩大总计算量；必须同时观察使用量与单位价格，而不能只看降本。
4. 先进制程、HBM、先进封装、网络和电力都是系统瓶颈，瓶颈迁移决定超额利润迁移。
5. 资本开支最终必须由云收入、广告效率、订阅和企业生产率变现，否则折旧压力将反噬估值。
6. 基础模型竞争正在从单一旗舰能力转向“能力、价格、开放权重、云分发和企业治理”组合竞争；模型层利润未必留在模型实验室，更可能被云平台和应用入口捕获。
7. 前沿模型训练仍在扩展，但公共高质量文本进入稀缺区间；下一阶段预期差来自数据质量、合成数据、后训练、推理时计算和企业私有数据入口，而不是单纯参数量。
8. 推理竞争从“最大模型”转向“最低足够成本”：缓存、Batch/Flex、KV cache管理、量化、蒸馏和任务路由决定真实单位成本，利润池向高利用率云平台、推理硬件和企业数据入口迁移。
9. AI Agent 基础设施的价值不在聊天入口，而在企业数据上下文、工具执行、权限治理、审计和可观测性；Microsoft、ServiceNow、Salesforce 等拥有系统记录和分发入口的平台优先级高于单点编排框架。
10. 向量数据库、数据工程和可观测性应合并理解为“AI数据上下文层”：纯向量检索正在平台化，真正的利润池更偏向数据云/湖仓、操作型数据库、实时数据流、权限治理和LLM/Agent可观测性。
11. 开源模型与商业化的核心不是“权重本身收费”，而是开放权重压低中低端推理价格、扩大部署量，并把利润池推向云推理、企业治理、数据上下文、模型路由、开发工具和应用入口。
12. 第3周周复盘将主线收敛为“训练仍消耗最大资本开支，超额收益迁向推理生产化控制面”：云推理、推理硬件/ASIC、企业数据上下文、Agent工作流和可观测性比单一模型权重更接近可验证利润池。
13. 编程助手已从 IDE 补全升级为软件交付工作流控制面；利润池更偏向仓库/PR、测试、代码审查、漏洞修复、权限审计和项目管理上下文，采用率高但信任、质量和用量治理决定企业化速度。
14. 企业知识与办公自动化的利润池正在从单点写作/会议摘要迁移到“身份权限、企业内容、系统记录、工作流执行和审计治理”的组合入口；Microsoft 365 Copilot 的付费席位最清晰，ServiceNow/Salesforce 的 AI ACV/ARR/AWU 更接近高价值业务流程，Google/Adobe/Zoom/Box/monday/Asana 需要继续验证 AI 使用量能否转化为续约、扩展率和可审计收入。
15. 客服与销售自动化的利润池正在从“降本 chatbot / 坐席助手”升级为连接客户数据、知识库、CRM、工单和全渠道触达的前台 agent 操作层；系统记录、联络中心实时性、通信触达、权限治理和可计费用量比单点问答能力更决定价值捕获。
16. 广告与推荐系统是 AI 应用中最早大规模变现的利润池，但真正壁垒不在单点生成式广告素材，而在搜索/社交/电商/短视频平台的高频意图数据、推荐模型、自动竞价、first-party data 和闭环转化反馈；Alphabet、Meta、Amazon、Tencent 的平台闭环强于开放互联网 DSP 和长尾创意工具。
17. 创意工具与视频生成的利润池不在一次性生成图片或短视频，而在专业/全民创作工作流、品牌与版权治理、多模型路由、内容真实性标记和广告/分发闭环；Adobe、Alphabet、Autodesk 质量优先，Canva/Runway 为私有参照，Getty/Shutterstock 更多作为版权内容库压力指标。
