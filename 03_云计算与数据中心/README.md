# 云计算与数据中心

## 研究主线

从云厂商资本开支出发，跟踪计算设备如何通过电力、网络和冷却转化为可售算力，并最终由云收入和应用变现覆盖折旧。

## 当前核心论文

1. 数据中心竞争正在从机房面积扩张转向可交付MW、已签未起租租约、电力接入和AI云收入转化。
2. 每MW价值量上升不等同于所有暴露标的受益；短期利润池更集中在电网/变电/EPC、电气设备、热管理和已通电容量。
3. 电网互联和长期PPA已经从ESG配套升级为speed-to-power、融资与客户信用的核心合同；firm power、non-firm接入和成本分摊规则决定可交付容量。
4. 已通电核心园区、可融资长期租约和低成本电力组合是未来12-24个月的主要利润池；土地储备本身不能直接等同于价值。
5. Hyperscaler云RPO和CapEx继续强化需求，但折旧、GPU更新、能源成本和社区许可会决定股权回报。
