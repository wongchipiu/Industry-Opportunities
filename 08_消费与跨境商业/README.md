# 消费与跨境商业

## 产业主线

消费与跨境出海研究按“人口与收入分层 - 渠道与内容基建 - 本土化合规准入 - 中国供应链协同角色 - 单元经济与复购”展开：

```text
区域宏观与城市消费分层（核心都市圈 vs 大众价格敏感层）
  → 渠道演变（现代零售 MT / 传统杂货 GT / 货架电商 / 短视频直播电商）
    → 监管与准入壁垒（进口门槛、清真认证 Halal、药品美妆备案 BPOM、本地投资 PT PMA）
      → 中国供应链角色（核心部件/设备/配方/数字化效率 + 本地组装/认证/渠道/售后）
        → SKU 单元经济（客单价、履约物流、退货率、账期与复购留存）
```

## 当前核心论文

1. **东南亚/印尼不可按单一人口总量线性外推，必须做城市与收入分层**：印尼 2.8 亿人口中大众层对价格高度敏感，视频电商典型客单价仅 US$4.5–6；真正具备高商业化确定性的是大雅加达（Jabodetabek）、西爪哇、万丹、泗水及巴厘岛等核心都市圈与工业聚集区。
2. **中国供应链在出海深水区的最优角色是“赋能者+本地化共创”而非低价成品倾销**：随着印尼贸易部 19/2026 号条例（跨境直售原则上 FOB ≥ US$100）、2026-10-18 起扩大强制清真认证（Halal）及 BPOM 备案执行，单纯廉价跨境铺货模式失效；高胜率模式是“中国提供核心零部件、工业设备、配方工艺与算法运营 + 印尼本地 OEM/组装、合规持证、备件仓与售后网络”。
3. **B2B 工业配套与高复购本地化快消优先级高于通用服装与低端 3C**：
   - **B2B 首选**：伴随印尼下游加工投资高增（2025 年同比 +43.3%）与 2025—2034 电力规划（新增 69.5GW 装机），**工业 MRO 耗材/自动化节能配套**、**冷链餐饮设备**及**工商业光伏储能**具备明确订单增量，竞争胜负手在于本地备件库存与工程师响应速度。
   - **B2C 首选**：**本地化美妆个护**（2026Q1 电商同比 +33%，结构性最强）、**浓缩家清防虫**与**摩托车/汽车后市场配件**（2026Q1 零售同比约 +12%）兼具高频复购与短视频演示优势。
