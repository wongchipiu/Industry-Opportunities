# 半导体

## 产业主线

半导体研究按“设计需求 - 晶圆制造 - 设备材料 - 封装测试 - 终端周期”展开：

```text
AI/HPC、手机、汽车、工业需求
  → 芯片设计与IP/EDA
    → 先进制程 / 成熟特色工艺
      → 光刻、刻蚀、薄膜、量测、材料
        → 先进封装、测试、基板
          → 库存、ASP、毛利率和资本开支周期
```

## 当前核心论文

1. AI/HPC把先进逻辑代工从普通制造产能推成系统瓶颈，领先者的壁垒来自良率、客户路线图、封装联动和设备交付，而不是单一节点命名。
2. 成熟/特色节点正在从低位修复，但补库存、ASP和利用率需要分开验证，不能把先进节点紧缺外推到所有代工资产。
3. 设备利润池仍集中在极少数关键环节，ASML光刻最稀缺；但出口管制和中国国产替代会改变DUV和中国收入的风险折价。
4. Samsung和Intel的先进Foundry修复是重要变量，但在外部客户、良率、量产收入和亏损收敛没有连续证据前，只能按“修复观察”处理。
5. 中微公司的本土设备壁垒来自关键刻蚀步骤的量产验证、客户共研和装机数据；其定价权强在局部工艺而非全产品，前五大客户占比、导入折扣和新平台盈利是生态能否转化为利润的关键。
