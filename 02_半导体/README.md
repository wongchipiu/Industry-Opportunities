# 半导体

## 产业主线

半导体研究按“设计需求 - 晶圆制造 - 设备材料 - 封装测试 - 终端周期”展开：

```text
AI/HPC、手机、汽车、工业需求
  → 芯片设计与IP/EDA
    → 先进制程 / 成熟特色工艺
      → 光刻、刻蚀、薄膜、量测、材料
        → 先进封装、测试、基板
          → 库存、ASP、毛利率和资本开支周期
```

## 当前核心论文

1. AI/HPC把先进逻辑代工从普通制造产能推成系统瓶颈，领先者的壁垒来自良率、客户路线图、封装联动和设备交付，而不是单一节点命名。
2. 成熟/特色节点正在从低位修复，但补库存、ASP和利用率需要分开验证，不能把先进节点紧缺外推到所有代工资产。
3. 设备利润池仍集中在极少数关键环节，ASML光刻最稀缺；但出口管制和中国国产替代会改变DUV和中国收入的风险折价。
4. Samsung和Intel的先进Foundry修复是重要变量，但在外部客户、良率、量产收入和亏损收敛没有连续证据前，只能按“修复观察”处理。
5. 中微公司的本土设备壁垒来自关键刻蚀步骤的量产验证、客户共研和装机数据；其定价权强在局部工艺而非全产品，前五大客户占比、导入折扣和新平台盈利是生态能否转化为利润的关键。
6. 光刻与过程控制坐落于晶圆制造与先进封装利润池顶端：ASML在2026Q3中国系统占比回落至23%（全年预计~20%）的压力测试下，仍凭先进逻辑与HBM客户需求创€11.66B销售、57.5%毛利率与€3.3B装机服务新高，并将全年指引上修至€44B–45B；2027—2028年扩产约30%后产能仍紧缺。
7. 过程控制从前道GAA延伸至CoWoS/HBM先进封装，定价权甚至高于光刻硬件：KLA FY27 Q1实现62.7% Non-GAAP毛利率与创纪录46.1%营业利润率，2026年先进封装过程控制收入预计约US$1.1B（+70%+）；Onto Innovation（Q3收入+88%）与Camtek（约80%收入来自AI先进封装）承接封装检测高弹性，中科飞测在2026Q3迎来单季扭亏拐点。
8. 清洗设备受益于GAA、3D NAND与HBM步骤数扩张（占前道步骤15%–20%+），但因存在SCREEN、TEL、Lam及盛美上海/北方华创等多家合格供应商，营业利润率普遍在17%–22%之间；盛美上海在手订单同比增长88.20%至170.73亿元，后续重点跟踪跨品类平台转化与毛利纪律。
