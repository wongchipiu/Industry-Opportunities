## 一页结论

- 核心判断：AI Agent 基础设施的利润池不会只留在模型层，正在迁移到「企业系统入口 + 私有数据上下文 + 工具执行权限 + 观测/评测/安全治理」的组合平台。能把 Agent 变成可审计业务动作的公司，优先级高于单纯提供聊天界面的公司。
- 当前周期位置：从开发者试验进入早期生产化。OpenAI Responses/Agents SDK、Anthropic MCP、Google ADK/A2A 让工具连接和多 Agent 协作开始标准化；Salesforce、ServiceNow、Datadog、Cloudflare 已把 Agent 相关指标写入财报或产品叙事。
- 最大预期差：企业买单的不是「更聪明的对话」，而是可量化的自动完成工作单元、工单闭环、代码/运维动作、CRM 线索处理和安全审计。若 Agent 业务转化为消费计费和增量 RPO，传统 SaaS 的「被 AI 替代」叙事会被部分修正。
- 最值得跟踪的三个指标：Agent 工作单元/自动化任务数、AI/Agent ARR 或 ACV、AI 观测/网关流量与大客户净扩张。
- 全球标的优先级：Microsoft、ServiceNow、Salesforce 居前；Datadog 和 Cloudflare 是 Agent 生产化后的工具层受益者；UiPath、Snowflake、MongoDB、Elastic 更偏主题观察。

## 1. 定义与研究边界

### 研究什么

AI Agent 基础设施是让模型从「回答」变成「可控执行」的中间层，核心包括：

1. Agent runtime：多轮推理、任务规划、工具调用、状态管理、队列、重试和人工接管。
2. 工具连接协议：API、MCP、A2A、企业应用连接器、浏览器/计算机使用能力。
3. 企业数据上下文：CRM/ITSM/ERP/知识库/日志/代码/对象存储/向量检索。
4. 治理与安全：身份、权限、审计、敏感数据过滤、策略、成本限制。
5. 可观测性与评测：trace、prompt/model/tool 调用日志、质量评估、延迟、成本、异常动作告警。

### 不研究什么

- 不把通用大模型能力排名作为核心变量；该主题已在基础模型竞争报告覆盖。
- 不深入向量数据库和数据工程厂商的完整格局；路线图下一题单独覆盖。
- 不覆盖所有垂直 Agent 应用；本报告只看能被多个应用复用的基础设施和平台入口。

### 证据分层

- 事实：公司财报/IR、官方产品文档、官方协议说明中披露的收入、RPO、ARR、ACV、产品 GA 或协议发布。
- 推断：Agent 生产化会提高对数据上下文、权限治理、可观测性和工作流执行层的需求。
- 观点：投资优先级应偏向已有企业分发、系统记录和审计责任的平台，而非缺少企业入口的单点开发框架。

## 3. 需求、供给与周期

### 需求

- 企业需求从「员工试用」走向「流程级自动化」。Salesforce 披露 Q1 FY27 Agentforce 与 Data 360 ARR 近 34 亿美元，其中 Agentforce ARR 12 亿美元，Agentic Work Units 累计 38 亿、环比增长 111%；这说明供应商开始用工作完成量而非席位数描述 AI 价值。
- IT/服务流程是早期落地点。ServiceNow Q2 2026 订阅收入 38.77 亿美元、同比增长 24.5%，cRPO 132 亿美元、同比增长 21%，并披露 ServiceNow AI ACV 超过 10 亿美元；Agent 与工作流系统记录绑定，商业化证据强于多数纯应用。
- 平台工程和安全团队开始为 Agent 付费。Datadog Q2 2026 收入 11.2 亿美元、同比增长 36%，10万美元以上 ARR 客户约 4,720 家，并把 Agent Observability、Bits Agent Builder 等列为近期产品重点；Cloudflare Q2 2026 收入 6.961 亿美元、同比增长 36%，Current RPO 同比增长 35%，AI Gateway/Workers AI/边缘安全是 Agent 流量治理的自然入口。

### 供给

- 模型 API 正把 Agent 能力产品化。OpenAI 2025 年发布 Responses API、内置工具和 Agents SDK；Google ADK 和 A2A 支持多 Agent 系统；Anthropic MCP 把外部工具和数据连接标准化。这降低了 Agent 应用开发门槛，也压缩了单点编排框架的长期护城河。
- 企业软件厂商把 Agent 嵌入原有系统记录。Salesforce 把 Agentforce 放在 CRM/Data 360/Slack 工作流里，ServiceNow 将 Agent 叙事绑定 ITSM、Workflow Data Fabric 和安全/治理，Microsoft 通过 Microsoft 365、GitHub、Azure、Power Platform 和 OpenAI 生态形成多入口分发。
- 可观测性厂商把 Agent 视作新 telemetry 类型。Agent trace、工具调用、模型版本、prompt、成本和安全策略需要进入统一平台，否则企业很难把自动动作放进生产环境。

### 库存/价格/资本开支

- Agent 本身没有传统库存，但存在「试点库存」：大量 PoC 未进入生产，若自动化成功率、审批责任和成本控制不足，试点会堆积在创新部门而非进入业务预算。
- 价格正在从席位向混合计费转变：基础 SaaS 席位仍在，但 Agent SKU、工作单元、token、网关调用、trace/日志量和自动化任务量会成为增量收入。风险是客户要求用 AI 节省席位支出，反过来压低净扩张。
- 资本开支外溢到云和推理硬件。Agent 增加调用次数、上下文长度、工具调用和重试次数，对低成本推理、缓存、批处理和 GPU/ASIC 利用率提出更高要求，承接前一篇推理经济学主题。

## 4. 技术路线与成本曲线

Agent 生产化的成本曲线由四个变量决定：

1. 单次模型调用成本：模型路由、缓存、量化、蒸馏和批处理决定 token 单价。
2. 单任务调用次数：Agent 越自主，规划、检索、工具调用和反思次数越多；任务成功率如果不提升，会放大成本。
3. 工具执行成功率：权限、API 稳定性、schema、幂等、重试和人工接管决定真实完成成本。
4. 可观测性与合规成本：生产环境需要日志、trace、评测、审计和安全网关，这会把一部分利润池转移给 Datadog、Cloudflare、Elastic 等工具层。

关键技术路线：

- 标准协议：MCP 解决 Agent 到工具/数据的连接，A2A 解决 Agent 间协作。标准化降低集成成本，但也使连接层更容易商品化。
- 企业上下文：RAG/搜索/数据库只是底层能力；真正壁垒在权限、业务规则、数据血缘和系统记录。
- 安全执行：Agent 动作必须可限制、可回滚、可审计。没有治理层，企业不会把支付、客户承诺、生产系统变更交给 Agent。
- 评测闭环：离线 benchmark 不足以证明业务价值，生产指标要看完成率、升级人工率、错误动作率、单位任务成本和客户满意度。

## 5. 竞争格局

### 平台型赢家候选

- Microsoft：Microsoft Cloud Q4 FY26 收入 593 亿美元、同比增长 27%，商业 RPO 6,780 亿美元；Azure、Microsoft 365、GitHub、Power Platform、OpenAI 关系和企业身份体系形成 Agent 分发与治理组合。质量最高，但 AI CapEx 和估值预期也最高。
- ServiceNow：强在 ITSM/工作流系统记录、权限和审计，AI ACV 已超过 10 亿美元。若 Agent 先在 IT、HR、客服、风险和安全流程落地，ServiceNow 是最直接受益者之一。
- Salesforce：Agentforce ARR 12 亿美元、AWU 38 亿是稀缺的 Agent 用量披露。优势是 CRM/Data 360/Slack 的业务上下文；风险是传统 CRM 席位增长放缓以及 AI SKU 能否覆盖客户节省人力后的价格重谈。

### 工具层赢家候选

- Datadog：Agent 生产化会制造新一类 trace、LLM 调用、成本和安全事件。Datadog 的优势是已在云原生可观测性、日志、APM、安全中拥有统一平台；风险是客户用量优化会削弱增量消费。
- Cloudflare：AI Gateway、Workers AI、边缘网络和 Zero Trust 适合成为企业 AI 流量控制点。优势是网络位置和开发者平台；风险是 GAAP 亏损、估值和 AI 收入披露仍不够穿透。
- Elastic：搜索、日志和安全天然贴近 Agent 检索与观测，但增长率低于高景气平台，需观察 AI Search 是否带动再加速。

### 数据与执行层观察

- Snowflake/MongoDB：企业数据上下文和向量/搜索能力是 Agent 的燃料，但短期收入归因难。优势是数据位置，风险是被云原生和应用内置能力分流。
- UiPath：RPA 和流程自动化是 Agent 执行动作的自然承接层，ARR 仍在增长；但若 Agent runtime 被 Microsoft/ServiceNow/Salesforce 内置，UiPath 需要证明跨系统自动化和治理仍有独立预算。
- Palantir：AIP 代表「业务操作系统/主权 AI」方向，商业化强，但更偏应用/决策层，本报告不列为基础设施核心前三。

## 8. 三情景与估值

由于本轮实时行情源未稳定返回，以下只给反向估值框架，不给目标价。评分中「估值与赔率」已降权。

### Microsoft

- Bear：AI CapEx 折旧高于云/软件增量收入，Copilot/Agent 采用率低于预期，Azure 毛利率承压。估值应回到成熟云软件倍数。
- Base：Azure、Microsoft 365 Copilot、GitHub Copilot 和 Power Platform Agent 持续贡献消费和高价 SKU，RPO 支撑未来收入，AI CapEx 可被云收入吸收。
- Bull：Microsoft 成为企业 Agent 默认控制面，OpenAI/多模型生态、身份和治理形成高转换成本，AI 推动 Office/开发者/云三线再加速。

### ServiceNow

- Bear：AI 自动化减少付费席位，客户把工作流功能转向云厂商或自研 Agent，AI ACV 未转化为 cRPO 加速。
- Base：ITSM/安全/HR/客服流程中的 Agent 与 Now Platform 绑定，AI ACV 增长支撑 20% 左右订阅增长。
- Bull：ServiceNow 成为跨部门 Agent 控制塔，按工作流/任务/治理收费扩大 TAM，Rule of 60 叙事重新强化。

### Salesforce

- Bear：Agentforce 主要是现有客户防御性升级，传统 CRM 增长减速、并购和回购杠杆削弱 FCF 质量。
- Base：Data 360、Slack、CRM 业务规则带动 Agentforce ARR 和 AWU 增长，AI SKU 稳定提升净扩张。
- Bull：Agentforce 成为销售、服务、营销自动化默认入口，工作单元计费打开比席位更大的收入池。

### Datadog / Cloudflare

- Bear：客户优化 AI 用量，开源观测或云内置网关压缩第三方工具预算。
- Base：Agent 生产化带来更多 trace、日志、网关、DLP、成本控制需求，现有大客户多产品扩张。
- Bull：Agent 安全事故或成本失控使 AI 可观测性和网关成为强制预算，工具层收入增长再加速。

## 9. 催化剂、风险与证伪

### 催化剂

- Microsoft 下一财季披露 Copilot/Agent 付费席位、Azure AI 消耗或 RPO 中 AI 合同增量。
- Salesforce Agentforce ARR、AWU、Agentforce One Edition 预订继续高增，并证明对 cRPO 有拉动。
- ServiceNow AI ACV 从 10 亿美元继续上修，且 cRPO/订阅收入保持 20% 以上增长。
- Datadog Agent Observability、LLM Observability、AI Gateway 类产品进入更多七位数扩张合同。
- Cloudflare AI Gateway/Workers AI 与 Zero Trust 形成企业 AI 流量控制标准入口。

### 风险

- Agent 成功率低、人工接管率高，导致企业停留在 PoC。
- AI 自动化压低传统 SaaS 席位需求，新增 Agent 收入不能覆盖席位流失。
- 模型 API 和云厂商把 Agent runtime、工具连接和观测能力内置，压缩独立工具层。
- 安全事故、数据泄漏、越权操作触发监管或企业冻结部署。
- 估值已反映高增长，若收入披露模糊或 cRPO 不加速，股价赔率不足。

### 相反证据

- 传统 RPA 和低代码平台过去多次承诺端到端自动化，但在复杂企业流程中常受系统碎片、例外处理和组织责任阻碍。
- MCP/A2A 等标准降低连接壁垒，也会削弱连接器厂商和单点编排框架的定价权。
- 企业软件公司披露的 Agent 指标口径不统一，ARR、ACV、AWU、token 和工作单元不能简单横向比较。
- AI 模型能力提升可能让一部分工作流逻辑直接留在模型/云平台，绕过传统 SaaS 中间层。

### 证伪条件

- 连续两个季度 Agent 相关 ARR/ACV/AWU 增速显著放缓，且 cRPO 不再体现 AI 拉动。
- 客户明确以 AI 自动化为由压缩 Salesforce/ServiceNow/Microsoft 等核心席位，净扩张率下行。
- Datadog/Cloudflare 大客户 AI 用量优化导致收入增速和指引连续下修。
- 重大 Agent 越权或数据泄漏事件引发企业部署暂停或监管约束。
- 开源/云内置 Agent observability 和 gateway 足以满足企业生产需求，第三方工具附加预算消失。
