## 一页结论

- 核心判断：基础模型竞争已经从“谁的单一大模型最强”转为“旗舰模型、低成本模型、开源/开放权重生态、云分发、企业数据治理和推理成本”共同决定份额。闭源头部仍在最难推理、代码和多模态任务中领先，但开源/开放权重模型正在压低中低端推理价格，并把应用层议价权推向模型路由和云平台。
- 当前周期位置：能力仍在快速扩张，Epoch AI 估计 frontier language model 训练算力自2020年以来约5倍/年增长，训练成本约3.5倍/年增长；这意味着模型层仍资本密集，盈利验证要靠 API 价格、调用量、云收入和企业订阅共同兑现。
- 最大预期差：模型发布本身不是最强投资信号。更有投资含义的是“模型能力差距缩小但单位 token 价格下降”后，谁能把模型变成云消耗、办公席位、广告效率、开发者平台或手机/终端入口。
- 最值得跟踪的三个指标：前沿模型 API 有效价格、企业 AI 云/RPO 与 Copilot/Gemini/Agent 采用率、开源/开放权重模型在开发者下载量和托管推理平台中的份额。
- 全球标的优先级：Alphabet、Microsoft、Amazon、Meta、Alibaba 质量最高；Baidu、Tencent、Oracle、Salesforce 处于第二梯队观察。由于实时价格未稳定核验，本报告不升级任何标的为“候选”。

## 1. 定义与研究边界

本报告覆盖能训练、拥有或大规模分发基础模型的公司和生态，包括闭源 API、云平台模型服务、开放权重模型、企业 AI 助手与开发者平台。不覆盖单一 AI 应用、只做推理托管的 GPU 云、或硬件供应链，除非其直接影响模型竞争。

- 事实：OpenAI 官网列示 GPT-5 系列具备 400K context、最高 128K output，GPT-5 价格为 input US$1.25 / output US$10.00 每百万 token，mini 与 nano 更低；Anthropic 文档显示 Claude Fable 5、Opus 5、Sonnet 5 可通过 Bedrock 等渠道访问，Sonnet 5 截至2026-08-31执行 US$2/US$10 每百万 token 的 introductory pricing；Google Gemini API 公开列示 Gemini 3.x 多档价格和搜索 grounding 费用。
- 推断：前沿模型不是单一垄断市场，而是“高端推理溢价 + 低端推理价格战 + 企业分发渠道”三层市场。模型能力在头部收敛时，分发、成本和数据权限将比 benchmark 排名更影响商业利润。
- 观点：基础模型层最适合投向“模型能力 + 云/应用变现 + 资本负担可承受”的综合平台，而不是单押未上市模型实验室估值。

| 开放权重生态 | 可本地部署模型、微调、低成本推理 | 开发者、主权云、垂直行业 | 云托管、服务、硬件拉动 | 社区、许可、成本效率 | Meta Llama、Qwen、DeepSeek、Mistral |

利润池排序：短期最大利润仍在云平台和应用入口，因为它们能把模型能力转成现有账单；模型实验室虽然技术稀缺，但资本开支、人才和价格战会消耗利润。开放权重模型的投资价值更多体现在云托管、芯片利用率、开发者生态和中国/欧洲主权部署。

## 3. 需求、供给与周期

### 需求

企业需求正在从试点进入预算科目。Microsoft FY26 Q4披露 Microsoft Cloud 收入 US$59.3B、+27%，商业 RPO US$678B、+84%；Alphabet Q2 2026披露 Google Cloud 收入 US$24.8B、+82%，并称 Gemini Enterprise 已被接近90%的 Fortune 100 使用；Amazon Q2 2026披露 AWS 收入 US$42.2B、+37%，AWS operating income US$16.6B。

需求的核心分歧在于：AI 调用量增长能否超过单位 token 价格下降和折旧上升。若企业把 AI 当作“新增软件预算”，模型平台受益；若只是替代原有搜索、客服或开发预算，模型层会陷入价格竞争。

### 供给

供给端有三条路线：

1. 闭源前沿：OpenAI、Anthropic、Google 继续以旗舰模型维持高端推理、代码和多模态溢价。
2. 开放权重：Meta Llama、Alibaba Qwen、DeepSeek、Mistral 等压低模型可获得性门槛，并让企业在私有化、主权云和成本敏感任务上获得替代选择。
3. 云集成：Microsoft/AWS/Google/Alibaba/Baidu 用模型市场和托管推理把多模型选择变成云消耗，而不是押单一模型。

### 周期位置

当前是“能力快速迭代 + 价格下行 + CapEx高位”的中早期商业化阶段。积极信号是云收入与 RPO 仍强；负面信号是 Meta Q2 2026 CapEx 达 US$31.08B，并将2026全年 CapEx 指引收窄至 US$130B-145B，说明模型和应用投资正对自由现金流形成压力。

## 4. 技术路线与成本曲线

| 路线 | 投资含义 | 强化证据 | 相反证据 |
|---|---|---|---|
| 大规模预训练继续扩张 | 头部模型仍需海量算力，支持云和 GPU 需求 | Epoch AI：训练算力约5倍/年增长，训练成本约3.5倍/年增长 | 数据质量、能耗和资本回报可能成为瓶颈 |
| MoE、蒸馏、量化和缓存 | 单位推理成本下降，扩大调用量 | OpenAI/Google/DeepSeek 均提供更低价模型层级或低价 API | 价格下降可能让模型层毛利被竞争吞噬 |
| 多模态与 Agent | 从聊天转向工作流执行，提升企业付费意愿 | Claude、Gemini、GPT、Qwen 均强化代码、多模态和工具调用 | 安全、权限和幻觉风险限制自动化范围 |
| 开放权重与私有部署 | 推动主权云、金融、制造、政务采用 | Qwen/DeepSeek/Llama 生态提升可替代性 | 最强前沿能力、数据治理和安全责任仍不透明 |

成本曲线结论：单位智能价格长期下行，但总支出不一定下降。若降价带来更高使用频率和更多 Agent 步数，云消耗、数据服务和安全治理反而会扩大；若应用 ROI 无法证明，企业会使用低成本模型路由压缩模型供应商利润。

## 6. 未来6-24个月关键变量

1. API价格：GPT、Claude、Gemini、Qwen、DeepSeek 的有效 input/output 价格和缓存折扣是否继续下调。
2. 企业采用：Microsoft Copilot、Gemini Enterprise、AWS Bedrock、Alibaba Model Studio、Baidu AI Cloud 的企业客户数和收入披露。
3. 云收入覆盖：AI云收入增长是否超过 GPU 折旧、电力、网络和数据中心租赁成本。
4. 开放权重份额：Llama/Qwen/DeepSeek/Mistral 在 Hugging Face、OpenRouter、云市场和企业私有部署中的使用趋势。
5. 监管安全：美国、欧盟、中国对前沿模型评测、开放权重出口、数据驻留和模型安全的规则。
6. 应用入口：搜索、办公、广告、代码和客服场景是否形成可量化生产率或广告转化提升。

## 10. 催化剂、风险与证伪

### 催化剂

- OpenAI、Anthropic、Google 或中国头部模型发布显著降低单位价格，同时保持前沿能力。
- Microsoft、Alphabet、Amazon 披露 AI 相关云收入、RPO、Copilot/Gemini/Bedrock 采用率继续加速。
- Meta Llama、Alibaba Qwen、DeepSeek 在企业私有部署或云托管使用量中持续提升份额。
- 企业 Agent 产品从试点转为标准席位或用量计费，软件公司开始披露可量化AI收入。

### 风险

- 模型能力快速同质化导致 API 价格战，模型层利润向云和应用入口转移。
- 训练与推理 CapEx 高于收入增长，云厂商自由现金流和估值倍数受压。
- 安全、版权、数据驻留和出口管制改变模型发布节奏或开放权重生态。
- Benchmark 与真实生产力脱节，企业预算回流到传统软件或低成本模型路由。
- 中国模型海外采用受合规和地缘限制，美国模型在中国市场受硬件与监管约束。

### 证伪条件

- 头部云厂商连续两个季度 AI 云收入/RPO放缓，同时CapEx继续上行。
- 单位 token 价格下跌超过调用量增长，导致模型服务毛利率明显下降。
- Copilot/Gemini/Agent 类产品付费留存和扩席不达公司指引。
- 开放权重模型在企业私有部署中没有形成稳定工作负载，只停留在开发者试验。
- 监管要求显著限制开放权重模型下载、跨境调用或训练数据使用。
