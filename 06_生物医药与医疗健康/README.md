# 生物医药与医疗健康

## 产业主线

生物医药与生命科学研究按“靶点与模态创新 - 临床与外包赋能 - 商业化放量与支付 - 上游工具耗材复购”展开：

```text
前沿治疗模态（GLP-1 / ADC / 双抗 / CGT / mRNA）
  → 药物发现与临床开发（CRO / SMO / 真实世界数据）
    → 工艺开发与规模化制造（CDMO / CRDMO / 多肽与偶联产线）
      → 生命科学工具、层析介质、生物工艺耗材与药用包材（卖铲子）
        → 监管获批、医保/商保支付、产能利用率与专利悬崖
```

## 当前核心论文

1. **终端创新药与“卖铲子”必须拆开定价**：近端商业现金流与处方确定性最强的是 **GLP-1**（Lilly 两大替尔泊肽品牌 FY25 销售 US$36.5B，Novo 三大司美格鲁肽品牌 DKK 229.5B）；而上游“卖铲子”弹性最高的是 **ADC**（linker、payload、偶联工艺、纯化与分析检测具备高工艺复杂度与跨项目复购属性）。
2. **管线试验数量不等于上游外包盈利能力**：截至 2026-08-07，CGT 活跃干预性临床试验达 2,061 项（远超 GLP-1 的 777 项与 ADC 的 565 项），但受制于自体制备成本、收治中心与支付瓶颈，部分 CGT CDMO 仍处于毛亏状态（产能利用率决定生死）。
3. **双抗跨过肿瘤单适应症验证，mRNA 仍处去产能周期**：双抗（Hemlibra + Vabysmo FY25 合计 CHF 8.856B）可高度复用成熟大分子生产与纯化平台；mRNA（活跃试验 95 项）在疫情后经历需求与原料去产能（如 Maravai TriLink FY25 收入 -39%），需等待肿瘤与非新冠疫苗后期数据催化。
4. **外包与工具环节遵循“CRDMO/耗材 > 临床CRO > 单纯CMO”的壁垒梯度**：具备分子漏斗跟随能力的 CRDMO（如药明康德 FY25 TIDES 收入 +96%、持续经营在手订单 580 亿元）与跨模态生物工艺龙头（Thermo Fisher、Danaher、Repligen、West Pharma、纳微科技）锁定性最强，但需持续跟踪地缘政策与估值安全边际。
